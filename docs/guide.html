1. Install or update the theme

Back up first. Before installing or updating, make a backup with your host's backup tool or a plugin such as UpdraftPlus.
  1. In WordPress go to Appearance → Themes → Add New Theme → Upload Theme.
  2. Choose topicalbacklink.zip (in the 1-Theme folder of this package) and click Install Now. If the theme is already installed, choose Replace active with uploaded.
  3. Click Activate if it isn't active already.
  4. Go to Appearance → TopicalBacklink setup and click Run setup. This creates any missing pages (Home, Services, Pricing, Case studies, About, Contact, Blog), sets the homepage, and fills Services and Case studies with the starting content. It is safe to run again; it never overwrites content you have edited.
Updating from an older version? Your existing White-label service page and Collab Management case study page are moved into the new Services and Case studies sections automatically, at the same web addresses. The old copies are kept as drafts under Pages, and you can delete them once you're happy.

2. The fields plugin: ACF PRO

The editable sections use Advanced Custom Fields PRO, the same plugin that already powers the homepage fields. Nothing new to install: just keep it active and up to date under Plugins.

  • The Services, Case studies and Page headings fields are built into the theme. They appear on the edit screens automatically and are not listed under ACF → Field Groups, so they can't be changed or deleted there by accident.
  • Don't install Secure Custom Fields or the free Advanced Custom Fields alongside ACF PRO. They are versions of the same plugin and will conflict.
  • If ACF PRO is ever deactivated (e.g. the licence lapses), the site keeps displaying everything correctly; you just can't edit those sections until it's active again.

4. Edit the homepage

Open Pages → Home → Edit. Below the title you'll find a box for each section (Hero, Platform, Stats, Services, How we build links, Case studies, CTA, FAQ). Any field you leave empty shows the original design text.

Highlighting words in a heading: wrap them like this: Link building for <span class="mark">AI visibility</span>. They get the violet underline stroke.

"Our work" tiles: if you leave the homepage's case study list empty, the tiles show your first six Case studies automatically, so you only maintain them in one place.

5. Services

Change an existing service

  1. Go to Services → All services and click the service.
  2. The title is the service name. The box called Short description is the text shown on the Services page. Service image (right column) is its picture.
  3. The Service page content box has a tab for each section of the page: Listing card, Hero, Overview, Features, Process, Price estimator, Comparison, Case study & reviews, FAQ, Call to action.
  4. Edit, then click Update.

Add a new service

  1. Services → Add new service.
  2. Type the name, the short description, and set a service image.
  3. Fill in only the sections you want. Any section left empty is hidden, so a new service can start small (Hero + Overview) and grow later.
  4. Set its position on the Services page in Post Attributes → Order (1 = first).
  5. Click Publish. It appears on the Services page and in "Other ways we build authority" on the other service pages automatically.

Handy details

  • Highlighted words fields add the violet brush stroke after a heading. "Heading" = A link department that, "Highlighted words" = wears your badge.
  • Counters count up when the page loads: put the number in Number (e.g. 3500) and symbols in Before/After (e.g. +).
  • Comparison table: type yes or no for a tick or cross, or short text such as 90 days.
  • Price estimator: switch it on in its tab. Leave the bands empty to use the standard rate card.
  • Overview picture: choose an image, the white-label dashboard illustration, or nothing.
  • To hide a service without deleting it, switch it to Draft.

6. Case studies

  1. Case studies → Add new case study (or click an existing one).
  2. Title = the headline (e.g. "How Collab Management grew enquiries by 156%"). Summary = the text on the Case studies page. Main image = the picture.
  3. In Card & facts fill the client, industry, DR before/after, duration and headline result. These feed the cards on the Case studies page and the homepage tiles.
  4. The numbered tabs (1. Challenge to 5. Placements) are the story. Only the ones you fill in appear, and the "On this page" menu adjusts itself.
  5. Set the position with Post Attributes → Order, then Publish.

The results chart

  • X-axis labels: comma separated, one per point, e.g. Month 0,Month 1,Month 2.
  • Metrics: one row per tab above the chart. Values must have the same count as the labels, e.g. 19,21,24. Leave Chart top empty for automatic scaling.
  • Before / after bars size themselves from the two numbers.

To feature a case study on a service page, open the service → tab Case study & reviews → choose it in Featured case study.

7. The blog

  1. Posts → Add New Post. Write the article using Heading blocks: H2 for main sections, H3 for sub-points. The table of contents is built from these automatically.
  2. Set a Featured image and pick a Category in the right sidebar.
  3. In the sidebar panel Card & article settings: write the Card summary (shown on blog cards, about 140 to 160 characters), add Key takeaways (one per line), and switch off the table of contents if you don't want it.
  4. Publish.
  • The large featured article at the top of the blog is the newest post. To pin a different one, tick Stick to the top of the blog in that post's sidebar.
  • Category filter buttons appear automatically for every category that has at least one post.
  • The author box uses Users → Profile → Biographical Info. Profile photos come from gravatar.com.

8. Leads from the contact form

Every contact form message is saved under Leads and emailed to the address in Settings → General → Lead notification email (or the site admin email if empty). If emails don't arrive, install an SMTP plugin such as WP Mail SMTP; the leads are still saved in the dashboard.

9. Before launch checklist

  • Service images: White-label, Multi-lingual and Local have no image yet and show a purple placeholder. The old site displayed images loaded from other agencies' websites (ecomranker.com, tlinks.io, authority.builders), which were removed because they belong to those companies. Upload your own under each service → Service image.
  • Case study figures: the starting numbers are illustrative. Replace them with measured results.
  • Case study summaries: five of the six case studies only have card details. Add a Summary and fill in the story tabs when you have them.
  • Blog author: fill in your profile's display name and biographical info.
  • SEO: an SEO plugin (Yoast, Rank Math) is optional. The theme writes basic titles and descriptions itself and steps aside when one is installed.

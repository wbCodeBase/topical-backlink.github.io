TOPICALBACKLINK WEBSITE PACKAGE
===============================

What's inside
-------------
1-Theme/topicalbacklink.zip      The WordPress theme. Upload this in WordPress
                                 (do not unzip it first).
2-Guide/TopicalBacklink-Guide.html
                                 Step-by-step guide: installing, and managing the
                                 homepage, services, case studies and blog from the
                                 dashboard. Open it in any web browser.

Quick start
-----------
1. Back up your site.
2. WordPress > Appearance > Themes > Add New Theme > Upload Theme >
   choose 1-Theme/topicalbacklink.zip > Install (or "Replace active with uploaded").
3. Make sure Advanced Custom Fields PRO is active (Plugins). It already powers
   the homepage fields; Services and Case studies use it too.
4. Appearance > TopicalBacklink setup > Run setup.
5. Read the guide for everything else.

Requirements
------------
WordPress 5.8 or newer (tested on 7.1), PHP 7.4 or newer.

IMAGES
======

Placeholders live here as ph-*.svg. To use a real photo:

  1. Drop the file in this folder, e.g. white-label-outreach.jpg
  2. Change that <img>'s src from images/ph-16x9.svg to images/white-label-outreach.jpg
  3. Replace the alt text with a description of the actual photo

Keep the width/height attributes close to your real image's aspect ratio so the
page does not shift while it loads. Images are cropped with object-fit:cover, so
anything roughly 16:9 will sit correctly in the service rows.

  ph-16x9.svg   1200 x 675   service rows (current use)
  ph-4x3.svg    1200 x 900   spare
  ph-1x1.svg     900 x 900   spare
